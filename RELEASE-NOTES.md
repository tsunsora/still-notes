# Still Notes 1.9.0

## What's new

- **Settings.** A gear at the bottom of the sidebar opens one place for appearance and updates. It wears a dot when an update is ready to install.
- **Palette styles.** Choose how your color becomes a theme: Tonal spot, Vibrant, Expressive, Rainbow, Fruit salad, Monochrome, Neutral, or Content. Each option previews itself in your current color.
- **Pure black.** An option for black surfaces in the dark theme.
- **Newer Material color.** Themes are generated with the 2025 Material color spec, and a color that would make text hard to read falls back to Slate.
- **Smooth color changes.** Switching theme, color, or style fades between schemes instead of snapping. It respects Windows' reduced-motion setting.

## Install or upgrade

Version 1.6.7 and later update to this release automatically: it downloads in the background and installs when you close Still Notes. After this update, open **Settings** from the gear at the bottom of the sidebar to check now. Earlier versions should download **Still-Notes-Setup-1.9.0.exe** below and run it once to upgrade. Existing notes, saved folders, preferences, and shortcuts are preserved.

The installer does not have a Windows Authenticode certificate, so Windows may show an unknown-publisher warning. Automatic updates use a separate application-specific signing key and do not require that certificate.

Only open the installer manually. The accompanying `latest.yml`, `.exe.blockmap`, and `.exe.sig` files support automatic updates. **SHA256SUMS.txt** contains the installer checksum for manual download verification.
